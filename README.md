# 🩺 Healthcare ML Stroke Prediction

A Machine Learning web application built using Streamlit to predict stroke risk based on healthcare parameters.

## 🚀 Features
- Stroke risk prediction
- Interactive Streamlit UI
- ML model deployment
- Healthcare analytics

## 📂 Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
